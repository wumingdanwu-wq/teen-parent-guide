一起讨论 · 打印填写

我们的家庭小约定

从一个反复出现的问题开始，先试行，再调整。保留孩子表达不同意见的空间。

01 / 我们想一起解决的具体事情

02 / 孩子的需要与担忧

03 / 家长的需要与担忧

04 / 这次先试的一条约定（谁、何时、做什么）

05 / 父母也会做到的事

06 / 做不到时怎样求助、补救或商量例外

07 / 什么时候一起回顾和调整

一起讨论 · 打印填写

一次小小的亲子复盘

不是为了找出谁更有错，而是为了理解发生了什么，决定下一次可以怎样做。

01 / 这次发生了什么（只写事实）

02 / 各自有什么感受和需要

03 / 哪一部分有帮助

04 / 哪一部分没有帮助

05 / 下一次只改变哪一件事

06 / 我们需要谁、提供什么支持

07 / 下次回顾的时间
